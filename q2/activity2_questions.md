## 1.) Answer the following questions:
**a. What is duck typing, as explained in the video?**


**Answer:** Duck typing is another way to achieve polymorphism besides inheritance. It follows through the logic of "if it looks like a duck and quacks like a duck, then it must be a duck," where objects can be treated as different types so long as they meet the minimum required attributes or methods.


**b. What did the Car class need to have so it could work inside the same loop as Dog and Cat, even if it does not inherit from the Animal class?** 


**Answer:** The car only needed to have the minimum required attributes and/or methods to be classified as an "animal", like the "speak()" function and the "alive" attribute, in order work inside the same loop.
